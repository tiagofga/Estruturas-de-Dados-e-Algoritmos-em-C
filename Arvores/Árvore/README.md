# Árvore

Implementação de **árvore binária de busca (BST)** em C.

## Operações implementadas

- inserir nós
- buscar valores
- percorrer em ordem (in-order)
- destruir árvore

## Documentação

- [Referência completa em português](../../docs/Arvore.md)
- [English reference](../../docs/en/Tree.md)
- [AVL](../../docs/AVL.md)

## Executar

```bash
cd Árvore
make
make run
make test
make clean
```
